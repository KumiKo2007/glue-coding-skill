# Code of Conduct

This project follows a simple standard: be clear, kind, and useful.

## Expected behavior

- Discuss ideas, tradeoffs, and code with respect.
- Assume good intent when feedback is terse or technical.
- Keep issues and pull requests focused on improving the skill.
- Welcome users with different languages, backgrounds, and levels of engineering experience.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language
- Personal attacks instead of technical feedback
- Spam, low-effort promotion, or unrelated content

## Reporting

If something feels off, open an issue with context or contact the repository owner privately through GitHub.
